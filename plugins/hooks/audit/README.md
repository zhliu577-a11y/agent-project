# audit 示例钩子插件

这是一个“拖入即可用”的 hook 插件示例，演示添加与更换钩子的完整套路。

## 作用

把模型每次回复、每次工具调用的前后状态、每轮结束原因，
以追加方式写进本插件目录的 audit.log。

## 使用

1. 启动项目：`.venv\Scripts\python.exe main.py`
2. 启动日志应出现：`钩子网关已接入插件: audit`
3. 和模型对话（例如让它查询当前时间），然后打开本目录的 audit.log 查看记录

## 如何更换

- 改行为：覆盖本目录的 hook.py（保持 name 与 factory 契约不变），重启进程；
- 换一整套：把本目录整个删掉/移出，再拖入新的同名插件目录；切勿让两个启用
  插件目录的 name 相同，loader 会因“插件重名”直接报错；
- 临时停用：把 plugin.json 的 enabled 改成 false，重启即可（目录可留原地）。
